为什么处理图像时不直接用全连接层而使用卷积？
全连接层会把一张图片拍成一维，导致参数量很大且没有利用到图像的性质。
图像的两个天然特性：
特性一：平移不变性
一个图像中的某个物体平移后组成它的还是那些像素
全连接层没法理由这个特性，平移后会导致一维的输入变化——也就是说需要大量的数据去训练模型，让它学习这种关系。
特性二：局部性
识别图像物体，通常只需要看局部区域。
比如要识别杯子，只需要看杯子和周围像素的关系，不需要看整张图。

也就是说，对于同一张图片，卷积神经网络CNN可以做到复用图片参数(参数共享)，且权重数量不变（毕竟卷积核大小就是权重大小）。
卷积核不断在原图上进行扫描，计算每一层的特征图，并作为下一层的输入。
卷积层：用一个小窗口（比如 3×3），在图像上滑动，每次取一小块局部区域，和权重V做加权求和。这个权重V就是卷积核，也叫滤波器.
卷积：提取特征图；池化：缩小特征图；
最常见的是 最大池化（Max Pooling）。
建立一个池化窗口，然后根据步长去移动，取在窗口内的最大值作为特征。——池化不进行与卷积类似的算术运算——我不那么关心这个特征具体在这个小区域的哪个位置，我更关心这个区域有没有这个特征。
池化压缩特征，比如说看见轮子可能就可以判断跟轮子相连的会是车，因为轮子是车的特征。大概这么一个好像不是很恰当的例子。
Global Average Pooling（全局平均池化）：把特征图全部相加然后除以特征数量——(1+2+3+4+5+6+7+8+9) / 9 ——即保留整体响应
结果好像也就最大池化跟平均池化？好像也是。
池化窗口的步幅通常是自己的宽高，反正不会大于自身。

卷积层：把互相关包装成一个“层”
卷积层有两个需要训练的参数：卷积核权重+ 偏置
class Conv2D(nn.Module):
def init(self, kernel_size):
super().init()
self.weight = nn.Parameter(torch.rand(kernel_size)) # 随机初始化卷积核
self.bias = nn.Parameter(torch.zeros(1)) # 偏置初始化为0

def forward(self, x):
    return corr2d(x, self.weight) + self.bias            # 互相关 + 偏置

对于图像这种高维空间数据，卷积层通常比直接用全连接层高效得多。
卷积是针对具有空间结构的数据设计的一种特殊连接方式；全连接则是一种非常通用的连接方式。

题外：
现代CNN不再普遍使用池化，而是将池化层替换成卷积层，修改步长对特征图进行卷积。——现代 CNN 并不是完全不用池化，而是越来越多架构使用步幅卷积（stride > 1）等方式进行下采样，因此池化不再是唯一、甚至也不总是首选的下采样方法。
池化方案下，池化层并没有起到训练的作用，步幅卷积可以通过训练学习。
nn.Conv2d是PyTorch 内置并做 互相关 + 偏置 + 多通道 + 步幅 + 填充等功能

填充和步幅:
由于卷积运算会导致特征图逐渐变小，填充跟步幅就是为了调节变小的速度。
如果没有填充，那么随着神经网络的深入，最终会得到一个1x1的特征图，就没法再往下了。丢失了边缘像素。
通常在外围加上一圈0作为填充，比如说8x8，加一圈是10x10 3x3卷积后还是8x8，尺寸保持不变。
如果是3x3卷积核，通常只需要填充1——3×3 + padding=1 + stride=1 → 空间尺寸不变

输出宽高公式：n - k + p + 1
其中：
n = 输入尺寸
k = 卷积核尺寸
p = padding 总量
nkp分别带入对应边，宽高分开算。
nn.Conv2d(
64,//输入
128,//输出通道128，表示输出128张特征图
kernel_size=3,//3x3卷积核
stride=1,//步长
padding=1//填充
)
stride 和 padding 没有“必须同步增加”的关系

多输入多输出通道：
需要让网络能够处理多通道数据。
比如说RGB图片，
实际上是R,G,B三个通道，大小相同然后互相叠加。如果在之前的情况下，直接丢一张图片进去，网络对它是没办法的，因为处理的是单个二维矩阵，图片是三个二维矩阵叠加。
那么对应这样的输入，卷积核不可能只有一个。也就是说这三个通道上都要有一个卷积核。所以卷积核的形状是 通道x卷积宽x卷积高。在图片中，卷积核就是 3 x 3 x 3
最终它们分开运算，然后把结果值叠加输出一张二维输出特征图
卷积核的数量：
输入 x 输出 x 卷积核大小
1x1卷积核只看当前像素不混入空间参数所以相对于其他卷积核来说参数量会大幅下降，但是它也能够混合当前的通道。并且1x1卷积核相当于对当前位置的通道进行全连接。且空间尺寸不变。
主要是用来调整通道数量，融合通道。

汇聚层(池化层):
卷积负责“提取特征”，汇聚负责“压缩空间尺寸，同时让特征对位置的小变化不那么敏感”。
动机一：逐渐降低空间分辨率，聚集信息。
动机二：降低对位置的敏感性。
最常用的配置：池化窗口 2×2，步幅 2。这样输出尺寸正好是输入的一半。比如 8×8 的输入，池化后变成 4×4。
GELU 是什么激活函数：
Gaussian Error Linear Unit（高斯误差线性单元）
根据输入值的大小，对它进行“软过滤”。平滑地压制负数。
