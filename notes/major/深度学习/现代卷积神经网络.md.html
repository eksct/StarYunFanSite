AlexNet深度卷积神经网络：
在 AlexNet 出现之前，虽然 LeNet 在小数据集（如手写数字）上表现不错，但在更大、更真实的数据集上，卷积神经网络并没有展现出优势。
当时的主流做法是手工设计特征。研究者们发明了 SIFT、SURF、HOG 等算法来提取图像特征，然后把特征送入 SVM 等分类器进行训练。
AlexNet 的一个重要意义就是：不要人工规定特征是什么，让网络自己通过训练学习特征。
AlexNet 和 LeNet 的设计理念非常相似，都是“卷积 + 池化 + 全连接”的堆叠。但两者在规模和复杂度上有巨大的差异。更大、更深、更多、更大。AlexNet 的参数总量大约有 6000 万，远超 LeNet 的几万参数。
AlexNet 的四大核心创新
AlexNet 之所以能成功，不仅仅是因为它更大，更因为它引入了一系列关键的技术创新，这些创新至今仍是深度学习的基石。
🔥 创新一：ReLU 激活函数
LeNet 用的是 Sigmoid 激活函数。Sigmoid 有一个致命缺陷：当输入很大或很小时，它的导数趋近于零，导致梯度消失，深层网络根本无法训练。
AlexNet 改用 ReLU（修正线性单元）：正数保留，负数归零。它的导数在正区间恒为 1，不会衰减信号。这一改变极大地缓解了梯度消失问题，让训练速度大幅提升。
💧 创新二：Dropout 正则化
AlexNet 有 6000 万参数，而训练数据只有约 120 万张图片。参数远多于数据，过拟合风险极高。
AlexNet 在前两个全连接层中使用了 Dropout，随机“关掉”一部分神经元，迫使网络不过度依赖任何单个神经元，学习更鲁棒的特征。原文指出，Dropout 是 AlexNet 控制全连接层模型复杂度的关键手段。
🖼️ 创新三：数据增强
为了进一步对抗过拟合，AlexNet 在训练时对图像做了大量数据增强：随机裁剪、水平翻转、颜色变换等。这些操作在不改变图像标签的前提下，人工制造了更多训练样本，让模型见到更多变化，从而提升泛化能力。
原文提到，AlexNet 对每张图像随机提取 227×227 的裁剪区域，并加上水平镜像版本，极大地扩充了训练集的多样性。
🖥️ 创新四：双 GPU 并行训练
AlexNet 的 6000 万参数在当时单块 GPU 上放不下。作者把网络拆分到两块 GPU 上并行训练，这是工程上的创举，也是 AlexNet 能够训练成功的前提。
AlexNet提出了创新的ReLu激活函数，以及使用暂退法(Dropout)对神经元进行退行，并对输入图像进行更多复杂处理，提升了模型的学习能力。

当时是人告诉机器应该看什么，手工特征。而AlexNet则是机器自己学习应该看什么。

AlexNet模型设计：
在AlexNet的第一层，卷积窗口的形状是11×11。由于ImageNet中大多数图像的宽和高比MNIST图像的多10倍以上，因此，需要一个更大的卷积窗口来捕获目标。第二层中的卷积窗口形状被缩减为5×5，然后是3×3。此外，在第一层、第二层和第五层卷积层之后，加入窗口形状为3×3、步幅为2的最大汇聚层。而且，AlexNet的卷积通道数目是LeNet的10倍。

在最后一个卷积层后有两个全连接层，分别有4096个输出。这两个巨大的全连接层拥有将近1GB的模型参数。由于早期GPU显存有限，原版的AlexNet采用了双数据流设计，使得每个GPU只负责存储和计算模型的一半参数。——幸运的是，现在GPU显存相对充裕，所以现在很少需要跨GPU分解模型（因此，本书的AlexNet模型在这方面与原始论文稍有不同）。

VGG块：
其实就是一个层模板。毕竟对块的定义我们也知道，多个层叠加在一起都可以被称之为块，那么VGG块实际上就是一个模板，内置了一些层以及运算组件。
模板结构：
1、若干个 3×3 卷积层：每个后面都跟一个 ReLU 激活函数。
2、一个 2×2 最大池化层：步幅为 2，负责把特征图的高和宽减半。
VGG网络就是堆叠VGG块，然后再配上三个全连接层进行分类。
通道数翻倍：每个块通过池化层将特征图尺寸减半后，下一个块的输出通道数就翻一倍（如 64 → 128 → 256 → 512）

NiN（Network in Network，网络中的网络）：
核心思想是对传统卷积网络进行了一次“微创手术”，解决了之前网络（如AlexNet、VGG）参数过多、容易过拟合的问题。
它的核心贡献有两个：用“1×1卷积”增强了卷积层的非线性表达能力，以及用“全局平均池化”彻底取代了笨重的全连接层。
由于1×1卷积等价于在每个像素位置上应用一个全连接层，这三个卷积层（普通卷积 + 两个1×1卷积）就组成了一个微型多层感知机（MLP），可以提取更抽象、更复杂的特征。
一个NiN块的结构就是：
1、一个普通卷积层（如11×11, 5×5, 3×3），负责提取空间特征。
2、两个连续的 1×1 卷积层，作为微型MLP，负责对提取的特征进行非线性变换和通道融合。

最终让模型输出一个分类数量的通道数，然后使用GAP全局平均池化采样出每个分类的分数：
让最后一个NiN块的输出通道数 = 类别数（例如，10分类任务就输出10个通道）。
对每个通道的特征图做全局平均池化。也就是说，对每个通道的所有像素值求平均，得到一个数字。
接着送入Softmax进行分类。

GoogLeNet(含并行连结的网络):
靠堆深度，而是靠“拓宽”和“并行”来变强。而不是堆深度。——它的目标是——在相同的计算量下，提取到更丰富的特征，从而提升训练效果
Inception 块:
nception 块由 四条并行的路径 组成，输入数据同时送给这四条路径处理，最后把结果拼接在一起：
路径一：单个 1×1 卷积层。 这是最“轻量”的路径，用 1×1 的卷积核提取最基础的特征。
路径二：1×1 卷积 → 3×3 卷积。 先用 1×1 卷积把通道数“压小”，再用 3×3 卷积提取中等范围的特征。
路径三：1×1 卷积 → 5×5 卷积。 同样先用 1×1 卷积降维，再用 5×5 卷积提取更大范围的特征。
路径四：3×3 最大汇聚 → 1×1 卷积。 先做池化操作，再用 1×1 卷积调整通道数。
四条路径的输出在通道维度上拼接（concatenate），一起送给下一层。

GoogLeNet 一共使用了 9 个 Inception 块，加上一些辅助层，整体结构可以分成五个“模块”：
模块一： 一个 7×7 卷积 + 最大池化，类似 AlexNet 的开头，负责快速降低图像尺寸。
模块二： 1×1 卷积 → 3×3 卷积 → 最大池化，进一步提取特征并缩小尺寸。
模块三： 两个 Inception 块 + 最大池化。
模块四： 五个 Inception 块 + 最大池化，这是网络中 Inception 块最集中的部分。
模块五： 两个 Inception 块 + 全局平均池化层 + 全连接输出层。
每个 Inception 块内部的四条路径都使用了合适的填充，使得输入和输出的高、宽保持一致，这样多个 Inception 块可以方便地串联。
最终cat，需要特征图的宽高一致。

批量规范化：
BatchNorm 的核心作用，是把神经网络中某些层输出的数据调整到相对稳定的数值分布，再允许模型自己学习是否需要进一步调整。
深层网络的三大麻烦
麻烦 1：输入要标准化，中间层却没人管。做机器学习大家都知道，拿到真实数据第一步是把输入特征处理成“均值为 0、方差为 1”（比如房价预测里把面积、价格拉到同一量级）。这招对优化器非常友好。但问题是：这只管了“进门”，数据在网络里穿过一层又一层之后，中间层的数值又开始乱跑了。
麻烦 2：中间层数值分布“漂移”，学习率没法配。如果某一层的输出动不动是另一层的 100 倍，那对这一层合适的学习率对另一层可能就是灾难——想用一个学习率把全网络都伺候好，难。
输入参数在运行过程中会经过大量运算最终输出给下一层的时候数值偏移，分散大。虽然数值变大不代表神经网络一定训练不好，但是不同层的数值尺度和分布可能让优化过程变得不稳定或低效。
麻烦 3：网络越深越容易过拟合，正则化手段变得更重要。
批量规范化则是在训练过程中将每层的输出重新拉回标准输入，不再越来越大，且还会存在一点噪音，能够防止过拟合。
BN的流程：（送入批次数量）
BN(x) = γ · (x − μ) / σ + β
对这批数据进行求平均，接着本批数据减去平均值，再除以本批数据的标准差得到一组平均值为 0、标准差约为 1 的数据。接着乘以γ，再加上 β
也就是对数据先进行标准化操作，接着乘以γ，再加上 β。
减均值是做中心化处理，消除位置偏移。
减标准差是尺度调整，
之所以需要乘以γ，再加上 β，是因为BN 如果强制所有数据永远保持这个分布，就可能限制模型的表达能力。所以要加入一点模型可学习参数，模型自行调控增加灵活性。
（均值为 0、标准差为 1，并不一定是神经网络每一层都最适合的分布）

全连接层对层输出进行批量规范化后，再送入激活函数。在全连接层中，BN 通常是沿着批次维度，对每个输出特征分别计算统计量
卷积层也是同理，然后是对每个输出通道分别计算均值和方差。——它的处理逻辑是把当前批次图片的x通道全部混合起来计算均值跟标准差，对数值进行归一化处理。
比如说32批次，26x26特征图，64的输出通道。那么对每个通道 32x26x26 = 21632 都会进行归一化，并计算64次。
BN的训练跟预测是不一样的。
预测时：
BN 通常会在训练过程中维护运行均值（running mean）和运行方差（running variance）。
预测时使用这些统计量，而不是根据当前待预测的 Batch 重新计算统计量。

BatchNorm1d：
常用于全连接层的二维输入，例如 (batch_size, num_features)。对每个特征分别统计。
BatchNorm1d 并不只用于二维输入，它也能处理形如 (N, C, L) 的三维输入。这时会针对每个通道，综合批次和序列位置上的数值计算统计量。
BatchNorm2d：
常用于 CNN 的四维输入 (N, C, H, W)。对每个通道分别统计，同时利用批次维度和空间维度上的数值。
BatchNorm2d(64) 中的 2d 不是说输入数据只有两个维度，而是指它常用于二维空间特征图。实际输入张量通常是四维的。

好处：
让深层网络的训练更稳定；可能带来一定的正则化效果；让优化过程更容易进行

残差网络（ResNet）：
ResNet 的核心出发点：与其要求新增的层重新学习全部需要的内容，不如让它们只学习“需要改变的那一部分”。
残差块使训练1000层网络成为可能，简直就是一个里程碑。
解决退化问题（网络加深以后，连训练数据上的表现都可能变差，训练误差反而更高），并引入跳跃。
残差块的输出是 输出 = F(x) + x
残差块里，因为有一条 + x 的跳跃连接，梯度可以直接从后面传回前面，不需要经过中间那些层。这就像给梯度开了一条高速公路，极大缓解了梯度消失问题。
在普通网络里，让多层学成恒等映射 F(x) = x 很难。但在残差块里，只需要让 F(x) = 0 就行——把权重压到零，比学一个恒等映射容易得多。
ResNet则从根本上改变了网络的连接方式，让训练上百层甚至上千层的网络成为可能。
不让网络直接学目标映射H(x)，而是让它学“残差”。
如果理想映射就是恒等映射（什么都不做），那么网络只需要把 F(x) 的权重学成0即可。让几个卷积层的输出趋近于0，比让它们精确地学出“输出等于输入”，要容易得多。
关键要求：两条路径的输出形状必须一致，才能相加。如果残差路径改变了通道数或空间尺寸，就需要在跳跃连接上用一个1×1卷积来调整输入的维度，使其与残差路径的输出匹配
残差网络能够使得梯度在反向传播的时候顺着跳跃连接快速传回之前的层。
ResNet 不是在代码中显式地计算“目标减输入”，而是先设计 H(X)=X+F(X) 这种结构，再通过正常的反向传播训练，让主路径学到适合整个任务的残差变换。后续会不断训练，让 F(X)达到相近的期望差值。

DenseNet（稠密连接网络）：
有一个共享文件夹，不断把原始输出添加到里面。
能够让模型中的所有层看到前面的原始输出。
每一层的输出都被保留下来，直接送给后面所有层，而不是像ResNet那样被“加掉”。
沿着通道维度拼接起来，增加通道数量。

稠密块：密集连接发生的地方
稠密块是DenseNet的基本单元。在一个稠密块内部，每一层都接收前面所有层的输出作为输入，然后把自己的输出也“贡献”给后面所有层
稠密块内部的每一层通常由 批量规范化 → ReLU激活 → 3×3卷积 组成，这和ResNet改良版的架构一致
增长率，它决定了每一层新增多少个特征图（通道数）
不断增加、保留特征

过渡层：
由于不断的连接会导致特征图的通道数会不断膨胀。一个稠密块结束后，通道数可能已经非常大了。
过渡层通常由一个 1×1卷积 + 平均池化 组成。1×1卷积用来压缩通道数（比如把通道数减少一半），平均池化用来降低空间尺寸（让特征图变小）
压缩特征，控制通道数量和空间尺寸
减少通道数量跟计算规模

DenseNet的整体架构
以经典的DenseNet为例，整体流程是：
开头：一个卷积层 + 最大池化，快速降低图像尺寸。
主体：4个稠密块，中间用过渡层隔开。每个稠密块内部的层数逐渐增加（例如6层、12层、24层、16层），通道数也在增长。
结尾：全局平均池化 + 全连接层输出分类结果。
不同版本的DenseNet（DenseNet-121、DenseNet-169、DenseNet-201等）的区别主要在于稠密块里有多少层。数字越大，网络越深，性能通常也越好。
DenseNet的优点
特征复用，参数高效：每一层产生的特征图会被后面所有层共享使用，网络不需要重复学习已经存在的特征，因此可以用更少的参数达到同等甚至更好的效果。
缓解梯度消失：每一层都和前面所有层直接相连，梯度回传的路径非常短，可以有效地传到最前面的层。
鼓励特征传播：由于每一层都能看到所有前层的输出，信息在网络中的流动非常顺畅，不容易丢失。
隐式正则化效果：特征的高度复用降低了网络对冗余特征的依赖，在一定程度上可以减轻过拟合。
内存消耗大：这是DenseNet最明显的缺点。由于每一层都要保存前面所有层的输出（为了拼接），中间激活值占用的内存非常高，对硬件要求比较苛刻。
通道数膨胀：随着层数增加，拼接后的通道数会不断增长，即使有过渡层压缩，整体计算复杂度仍然比普通网络高。
调参仍然困难：和ResNet一样，DenseNet也有不少超参数需要仔细调整（增长率、压缩率、瓶颈层宽度等），训练起来并不轻松。
