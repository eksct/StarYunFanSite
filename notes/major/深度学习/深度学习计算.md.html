层和块:

层(Layer)：是神经网络的基本计算单元，它接收输入，产生输出，并拥有一组可调整的参数。比如一个全连接层。注意，有些块不需要任何参数。

想加多少层就加多少层。甚至可以用循环:

python
class BigNet(nn.Module):
    def __init__(self, num_layers):
        super().__init__()
        layers = []
        for _ in range(num_layers):
            layers.append(nn.Linear(256, 256))
            layers.append(nn.ReLU())
        self.hidden = nn.Sequential(*layers)
        self.out = nn.Linear(256, 10)

    def forward(self, X):
        return self.out(self.hidden(X))

块 (Block)：是对层的更高层次抽象。它可以描述单个层、由多个层组成的组件，甚至是整个模型本身。使用块的好处是可以将一些块组合成更大的组件，这个过程通常是递归的。这种设计让我们可以用简洁的代码实现复杂的神经网络

对于简单的、顺序执行的网络结构，PyTorch提供了nn.Sequential，它是一种特殊的块，维护了一个由模块组成的有序列表

python
import torch
from torch import nn

net = nn.Sequential(
    nn.Linear(20, 256),  # 第一层：输入20维，输出256维
    nn.ReLU(),           # 激活函数
    nn.Linear(256, 10)   # 第二层：输入256维，输出10维
)
X = torch.rand(2, 20)    # 创建一个2行20列的输入
net(X)                   # 前向传播，得到输出
python
nn.Linear(20, 256)   # 这就是一个块，虽然它只是一个层
nn.ReLU()            # 这也是一个块
block = nn.Sequential(
    nn.Linear(20, 256),
    nn.ReLU(),
    nn.Linear(256, 256),
    nn.ReLU()
)  # 这也是块
class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.feature = block                     # 上面那个组件
        self.classifier = nn.Linear(256, 10)     # 再来一层

    def forward(self, X):
        return self.classifier(self.feature(X))

整个模型也是块。

跳跃连接：

跳跃连接（也叫残差连接）是：把某一层的输入，直接“跳”过中间几层，加到后面某一层的输出上。

用代码表示就是：

python
def forward(self, X):
    return X + self.layer2(self.layer1(X))

这里的 X 没有经过 layer1 和 layer2，直接加到了它们的输出上。

为什么有用？ 因为它让梯度在反向传播时，有一条“高速公路”可以直接从后面传回前面，不用经过中间那些层。这极大地缓解了深层网络中的梯度消失问题。ResNet 就是靠这个，才能训练到上百层甚至上千层。

而 nn.Sequential 做不了跳跃连接，因为它只支持“一层接一层”的顺序执行。所以你才需要继承 nn.Module，在 forward 里手动写 X + ... 这样的操作。

nn.Sequential 负责按顺序连接模块，不能仅靠依次列出普通层就直接表达跳跃连接。

nn.Module 是什么？

nn.Module 是 PyTorch 里所有神经网络模块的基类。

你可以把它理解成一个“神经网络模块的模板”。它规定了一个模块应该具备哪些能力：

由于自动微分提供了一些后端实现，我们只需要考虑前向传播函数和必需的参数。

nn.Module 用于组织层、参数和前向计算；反向传播通常由 PyTorch 的自动求导机制完成，不需要我们手写。

  • 能存储参数（权重、偏置）；

  • 能前向传播（forward）；

  • 能自动求导；

  • 能注册子模块；

  • 能保存和加载；

  • 能在 CPU 和 GPU 之间移动。

nn.Linear、nn.ReLU、nn.Sequential、你自己写的 MLP，全都是 nn.Module 的子类。它们都继承了这个模板，所以都具备上述能力。

灵活定制：继承nn.Module

你自定义网络时，必须继承 nn.Module，这样 PyTorch 才会把你的类当成一个“正经的神经网络模块”来对待。

当网络结构不是简单的顺序堆叠时（例如，需要跳跃连接），就需要通过继承nn.Module类来定义自己的块。

自定义块的核心步骤：

  • 定义类：你的类需要继承nn.Module。

  • 实现__init__：在构造函数中，定义网络所需的层和参数。记得先调用super().init()来初始化父类。

  • 实现forward：定义数据如何通过网络向前传播，即如何根据输入X返回所需的模型输出。

forward 是前向传播函数，但反向传播函数不需要你写。

呃呃不过这玩意是卷积神经网络的东西了（=-=）

ResNet（Residual Network，残差网络）：

是深度学习历史上一个里程碑式的网络架构，由何恺明等人在 2015 年提出。它最著名的成就是：首次成功训练了超过 100 层的深度网络，并在当年的 ImageNet 竞赛中拿下冠军。

在 ResNet 出现之前，人们发现一个奇怪的现象：网络越深，训练误差反而越大。

按常理说，网络越深，表达能力越强，应该表现更好才对。但实际情况是，20 层的网络比 56 层的网络训练误差更低。这不是过拟合——过拟合是训练误差低、测试误差高；而这里是训练误差本身就高。

这个问题被称为退化问题（degradation problem）。深层网络可能遇到梯度消失，使前面的层难以学习。但即使缓解了梯度消失，加深网络仍可能使训练误差升高，这就是退化问题。残差连接通过让网络更容易保留输入、学习必要的调整，帮助缓解这种优化困难。

ResNet 的核心思想：残差块

ResNet 的解决方案非常简洁：不要让每一层直接学“目标输出”，而是让它学“目标输出与输入之间的差值（残差）”。

一个普通的网络层是：输出 = F(x)

ResNet 把它改成：输出 = F(x) + x

python
def forward(self, X):
    return F.relu(self.layer2(self.layer1(X)) + X)

残差块里，因为有一条 + x 的跳跃连接，梯度可以直接从后面传回前面，不需要经过中间那些层。这就像给梯度开了一条高速公路，极大缓解了梯度消失问题。

在普通网络里，让多层学成恒等映射 F(x) = x 很难。但在残差块里，只需要让 F(x) = 0 就行——把权重压到零，比学一个恒等映射容易得多。

所以，多加几层残差块，最坏情况也就是“什么也没学到”，这给了深层网络一个“保底”能力。(增加的层即使没学到有用的东西，至少可以原样传递输入。)但不保证实际训练后一定不会变差。但实际训练不一定找到这样的参数，因此不能保证加深后一定不会变差。

ResNet 的历史地位

它证明了“深度”本身是有价值的：在 ResNet 之前，人们不敢把网络做得太深，因为训练不动。ResNet 之后，上百层甚至上千层的网络成为可能。

ResNet 对后来的深层网络设计产生了深远影响。例如，DenseNet 进一步发展了跨层连接的思路，后来的 Inception-ResNet 和 Transformer 也采用了残差连接。

它让“跳跃连接”成为标准组件：现在几乎所有的深层网络都会在某个地方用到跳跃连接。

退化问题是指：随着网络层数加深，训练误差反而变大，而且这不是过拟合造成的。

根源在于：现有的优化方法（如SGD）很难让多层非线性层学会“恒等映射”。让一堆层学成“输入等于输出”，对普通网络来说非常困难。

ResNet的解决方案就是：既然让网络直接学恒等映射很难，那我就用跳跃连接把恒等映射“送过去”，只让中间层学“残差”。

ResNet结构最终的输出是：中间层学到的F(x) + x

残差是相对于“当前层的输入”定义的

残差 = 目标输出 - 当前输入

5.2. 参数管理

训练完模型后，我们通常需要：

  • 查看参数：调试、诊断、可视化，看看模型到底学到了什么。

  • 初始化参数：好的初始化能让训练更快、更稳定。

  • 共享参数：让不同层使用同一组参数，减少参数量，还能让模型学到“通用”的特征。

nn.Sequential 像列表一样，可以用索引访问任意一层

python
print(net[2].state_dict())

state_dict() 返回一个字典，键是参数名，值是参数张量。每个参数都存储为 float32

注意：state_dict() 可以查看模型的参数等状态。在这个示例中，全连接层的权重和偏置都是 float32 类型；其他模型的实际类型取决于其设置。

访问参数的值和梯度：

参数是 Parameter 类的实例，它包含值、梯度和额外信息。要拿到具体数值，需要用 .data

python
print(type(net[2].bias))        # <class 'torch.nn.parameter.Parameter'>
print(net[2].bias)              # Parameter containing: tensor([-0.0291], requires_grad=True)
print(net[2].bias.data)         # tensor([-0.0291])
print(net[2].weight.grad)       # None（还没做反向传播）

延后初始化：

神经网络先把“结构”搭起来，但暂时不知道参数具体有多大，等第一次看到输入数据后，再根据输入的形状自动确定参数大小。

自定义层 ：

说白了就是使用nn.module自定义一个块咯，而在这里块也可也作为层。毕竟就一个。

自己定义一个“输入 → 某种计算 → 输出”的模块，然后让 PyTorch 把它当成普通神经网络层使用。

没有任何学习参数的层：

python
class CenteredLayer(nn.Module):
    def __init__(self):
        super().__init__()

    def forward(self, X):
        return X - X.mean()

带可学习参数的自定义层：

使用nn.Parameter自定义参数，nn.Parameter 会告诉 PyTorch：这个张量是模型参数，需要被自动注册，并在训练时被优化器更新。

requires_grad = false设置是否参与梯度计算

自定义的参数如果想要自动更新，必须参与计算，且对loss有影响。

python
class MyLinear(nn.Module):
    def __init__(self, in_units, units):
        super().__init__()
        self.weight = nn.Parameter(torch.randn(in_units, units))
        self.bias = nn.Parameter(torch.randn(units,))

    def forward(self, X):
        linear = torch.matmul(X, self.weight.data) + self.bias.data
        return F.relu(linear)

register_buffer：专门为“不训练但需要管理”的张量设计

register_buffer 注册的张量：

  • 不参与梯度计算；

  • 不在 model.parameters() 里（优化器看不到）；

  • 但会随模型保存/加载；

  • 会随模型移动到 GPU。

这非常适合那些“需要持久化、需要跟着模型走、但不需要训练”的张量。比如 Batch Normalization 里的 running_mean 和 running_var，就是用 buffer 注册的。

可以作为一个模块的属性，也存储在内部的_buffers字段内。

python
class MyLayer(nn.Module):
    def __init__(self):
        super().__init__()
        self.register_buffer('running_mean', torch.zeros(5))

    def forward(self, X):
        return X - self.running_mean

核心原则：数据和模型必须在同一个设备上。跨设备运算会报错。设备之间的数据传输很慢，要尽量减少搬运次数，尽量批量搬运。

python
X = torch.ones(2, 3, device="cuda:0")

书里还定义了两个实用函数，方便在代码中自动选择设备

python
def try_gpu(i=0):
    """如果存在，则返回 gpu(i)，否则返回 cpu()"""
    if torch.cuda.device_count() >= i + 1:
        return torch.device(f'cuda:{i}')
    return torch.device('cpu')

def try_all_gpus():
    """返回所有可用的GPU，如果没有GPU，则返回[cpu()]"""
    devices = [torch.device(f'cuda:{i}')
               for i in range(torch.cuda.device_count())]
    return devices if devices else [torch.device('cpu')]

那 .cuda() 是干什么的？

就是把 Tensor 复制到 GPU。

补充：教材 MyLinear 示例中的 .data

“自定义层”中的 PyTorch 示例使用了：

python
def forward(self, X):
    linear = torch.matmul(X, self.weight.data) + self.bias.data
    return F.relu(linear)

这段代码可以完成前向计算，但通过 .data 参与计算的权重和偏置，无法从这条路径获得训练所需的梯度。教材后面的演示只做了参数查看和前向计算，没有验证反向传播，所以没有暴露这个问题。

用于训练时，应改成：

python
def forward(self, X):
    linear = torch.matmul(X, self.weight) + self.bias
    return F.relu(linear)

这与上一条“查看参数时使用 .data”有区别：这里是在构造损失所依赖的前向计算，必须保留参数的梯度路径。查看数值可以使用 detach()。
