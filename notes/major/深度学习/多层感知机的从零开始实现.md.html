以下代码对照教材的 PyTorch 版本整理，各代码块在安装了 PyTorch、torchvision 和 d2l 的 Notebook 环境中按顺序执行。

python
import torch
from torch import nn  # 神经网络模块
from d2l import torch as d2l

加载数据

python
batch_size = 256
train_iter, test_iter = d2l.load_data_fashion_mnist(batch_size)

初始化模型参数

每张 Fashion-MNIST 图片有 28×28 个像素，展开后有 784 个输入特征。10 是类别数，256 是隐藏层的神经元数量。

第一层权重矩阵 W1 的形状是 (784, 256)，将 784 维输入映射到 256 维隐藏表示；第二层权重矩阵 W2 的形状是 (256, 10)，将隐藏表示映射到 10 个类别得分。torch.randn 生成随机数，乘以 0.01 使初始权重较小。

requires_grad=True 表示需要计算梯度，nn.Parameter 将这些张量作为模型参数使用。下面的优化器会根据梯度更新 params 中的参数。

python
num_inputs, num_outputs, num_hiddens = 784, 10, 256

W1 = nn.Parameter(
    torch.randn(num_inputs, num_hiddens, requires_grad=True) * 0.01
)
b1 = nn.Parameter(torch.zeros(num_hiddens, requires_grad=True))

W2 = nn.Parameter(
    torch.randn(num_hiddens, num_outputs, requires_grad=True) * 0.01
)
b2 = nn.Parameter(torch.zeros(num_outputs, requires_grad=True))

params = [W1, b1, W2, b2]

两层偏置都用 0 初始化：b1 有 256 个零，b2 有 10 个零。这里的 10 是元素数量，不是填充值。

自定义 ReLU 激活函数

ReLU 将正数原样保留，非正数变成 0。按照教材写法，先用 torch.zeros_like(X) 创建与输入形状、数据类型和设备相同的全零张量，再逐元素取较大值。

python
def relu(X):
    a = torch.zeros_like(X)
    return torch.max(X, a)

定义模型

把每张图片展开为长度 784 的向量。reshape((-1, num_inputs)) 中的 -1 表示自动推算批量大小；例如一批 256 张图片，展开后的形状为 (256, 784)。

@ 表示矩阵乘法，与这里原先使用的 torch.matmul 含义相同。第一层得到形状为 (256, 256) 的隐藏表示，经过 ReLU 后，第二层输出形状为 (256, 10) 的类别得分。这里的 256 是这个例子的批量大小，最后一个批次的样本数可能更少。

python
def net(X):
    X = X.reshape((-1, num_inputs))
    H = relu(X @ W1 + b1)
    return H @ W2 + b2

损失函数

nn.CrossEntropyLoss 直接接收模型输出的未归一化类别得分，不需要先手动调用 Softmax。

按照本节 D2L 训练辅助函数的约定，设置 reduction='none'，保留每个样本的损失，由训练函数负责求平均、反向传播和统计。

python
loss = nn.CrossEntropyLoss(reduction='none')

训练

训练 10 轮，学习率设为 0.1。先创建与 params 关联的 SGD 优化器实例，再把它传给 d2l.train_ch3。

python
num_epochs, lr = 10, 0.1
updater = torch.optim.SGD(params, lr=lr)
d2l.train_ch3(net, train_iter, test_iter, loss, num_epochs, updater)
