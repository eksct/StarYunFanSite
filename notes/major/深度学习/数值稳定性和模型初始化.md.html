初始化方案的选择在神经网络学习中起着举足轻重的作用， 它对保持数值稳定性至关重要。

梯度是"一长串矩阵连乘"的结果。而矩阵的连乘由它们的特征值决定：有些特征值很小、有些很大，乘积就会指数级地趋近 0 或冲上天。这比"很多概率相乘导致下溢"更难办——概率乘起来一定是变小的，而矩阵乘积两个方向都可能失控。

梯度消失：

参数每次更新只挪动一丁点，损失曲线长期不动，看起来像"学不动"。

sigmoid函数是导致梯度消失问题的一个常见的原因。

Sigmoid函数会把输入“压扁”到0到1之间。当输入很大或很小时，它的曲线会变得非常平坦，梯度（导数）几乎为零。在反向传播时，每经过一个Sigmoid层，梯度就被乘以一个接近0的数，多层叠加后，梯度就消失了。

ReLU函数如何缓解这个问题？

ReLU在输入为正数时，梯度恒为1，不会“衰减”信号。因此有效缓解了梯度消失问题，成为现代网络的默认选择。但它不能保证整个网络完全不会出现梯度消失或梯度爆炸。

梯度爆炸:

参数更新幅度巨大，损失剧烈震荡甚至变成 NaN，优化器彻底失去收敛的可能。

书里做了一个实验：创建一个随机矩阵，然后反复乘以100个随机矩阵。结果，这个矩阵中的数值会变得极其巨大（如10的26次方），矩阵乘积发生爆炸，数值特别巨大。这形象地说明了，如果权重矩阵的数值稍大，经过多层连乘后，梯度就会爆炸。

打破对称性：不能让所有神经元“复制粘贴”：

如果网络里所有隐藏单元的初始权重都设成完全一样的值，那它们就像是同一个人的“复制粘贴”，无论怎么训练，它们永远都学一样的东西，网络就失去了多样性。所以会用随机值来初始化权重，打破这种对称性，让每个神经元从不同的起点开始学习。但是打破对称性不等于所有参数都必须随机，关键是让需要分工的隐藏单元有不同的学习起点或路径，而不是禁止任何零初始化。

如何正确初始化？Xavier初始化：

Xavier初始化要解决的问题是：既然随机初始化很重要，那应该用什么分布、多大的范围来随机呢？

它的核心思想：让每层的“信号强度”保持一致

Xavier初始化的目标是：让每一层输出的方差，和它输入的方差大致相等(核心原因是为了让信号在网络中稳定地流动，避免训练时出现“梯度消失”或“梯度爆炸”)。

它根据每层的输入、输出数量设置初始权重的大小，尽量避免信号和梯度随着层数增加而不断放大或缩小，从而缓解梯度消失和梯度爆炸问题。但这不代表无论网络多深，都能保证稳定。

怎么做？根据层的“大小”来缩放

它根据一个层的输入神经元数量（nin）和输出神经元数量（nout），来决定权重的随机范围。公式是：

text
权重方差 = 2 / (nin + nout)

这意味着：如果一个层的输入或输出神经元特别多，就用更小的随机值来初始化。这样，当信号经过这个“大”层时，就不会因为元素太多而累加出过大的方差。

注意：ReLU需要专用初始化

当输入分布关于零对称时，ReLU 会将负数部分置零，使输出的“平方后求平均”变为输入的一半。Kaiming 初始化考虑了这种影响，调整初始权重的大小，以帮助信号稳定传播。

平方后求平均”不等于“方差。

补充： ReLU 会把负数部分置零，改变信号传播时的统计特性。Kaiming 初始化专门考虑了这种影响，调整初始权重的大小，使 ReLU 网络中的信号和梯度更容易稳定传播。它与 Xavier 的具体设置不同，不能一概理解成“把 Xavier 的方差乘以 2”。

“在 Xavier 基础上把方差乘以 2”不是通用关系。 常见 Xavier 权重方差为 2 / (输入数 + 输出数)；适用于 ReLU、兼顾前向传播的 Kaiming 方差为 2 / 输入数。只有输入数等于输出数时，后者才恰好是前者的两倍。

为什么根据输入（nin）和输出（nout）神经元数量，来决定权重的随机范围——因为方差的稳定性是由权重的方差和神经元数量共同决定的

一个神经元的输出，是它所有输入加权求和的结果。如果输入神经元的数量（nin）很多，每个输入乘以一个不大不小的权重，加起来后，输出的方差就会因为累加而变得很大。为了抵消这种“累加效应”，就需要让每个权重的值（也就是方差）变小一些。权重方差需要和输入神经元数量成反比。

同理，反向传播时，梯度是从输出端往输入端传的，所以梯度的稳定性又和输出神经元的数量（nout）有关。

Xavier 初始化就是同时考虑了这两个方向，取了一个折中：让权重的方差与 (nin + nout) 成反比，并乘以 2。这样，信号在前向和反向传播时，都能保持相对的稳定。

Kaiming 初始化是什么？

Kaiming 初始化（也叫 He 初始化）是专门为 ReLU 激活函数设计的权重初始化方法

为什么 Xavier 不适合 ReLU？

Kaiming 初始化是怎么修正的？

Kaiming 初始化的做法非常直接：既然 ReLU 会把方差减半，那我就把初始权重的方差再乘以 2，来补偿这个损失。

所以，Kaiming 初始化的方差公式是：

text
方差 = 2 / nin

而 Xavier 的折中公式是：

text
方差 = 2 / (nin + nout)

可以看到，Kaiming 初始化只考虑了输入神经元的数量（nin），并且把分子从“2”保留了下来。这个“2”就是为了补偿 ReLU 砍掉一半信号带来的方差损失。
